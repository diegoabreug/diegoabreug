## About

Software Engineering student at **INTEC** (GPA 3.81) who builds production-minded software across the stack, from **multi-agent AI pipelines** to **cloud infrastructure**.

- **AI engineering:** agentic systems with LangGraph and LLMs, with orchestration, failure handling and per-step observability.
- **Full-stack development:** FastAPI and Flask backends, Next.js and Flutter frontends, PostgreSQL and Firebase data layers.
- **Cloud & DevOps:** infrastructure as code with Terraform and Ansible, GitOps delivery with Helm and Argo CD on Kubernetes.
- **Product mindset:** I start from the user's problem, ship a working version fast, and iterate with real feedback.

**Open to:** Software Engineering · AI/ML Engineering · Full-Stack · Internships and new-grad roles · Remote or on-site (relocating to the United States)

## Featured Projects

<summary><b>CV Job Match Agent</b>: agentic AI that scores a CV against any job posting</summary>

<br/>

A 4-agent pipeline (CV Parser → Job Analyzer → Gap Analyzer → Recommender) that produces a match score, a gap analysis and actionable recommendations.

| | |
|:--|:--|
| **Stack** | Python · FastAPI · LangGraph · Groq · Supabase (PostgreSQL) · Next.js · TypeScript · Tailwind |
| **Architecture** | LangGraph state machine with conditional routing: if any agent fails, the pipeline stops before errors cascade |
| **Observability** | Every agent step is logged to Supabase with input summary, output summary and latency |
| **Deployment** | FastAPI on Render, Next.js on Vercel, PostgreSQL on Supabase, on $0 infrastructure |
| **Links** | [Repository](https://github.com/diegoabreug/cv-job-agent) · [Live demo](https://frontend-five-tau-a92oojj0mf.vercel.app) |
